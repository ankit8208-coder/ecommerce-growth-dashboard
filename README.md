# GrowthPulse — E-Commerce Performance & Growth Dashboard

A responsive, assignment-ready dashboard for the E-Commerce Performance & Growth Challenge.

## Included
- Executive KPI dashboard
- Root-cause analysis
- Competitor/product listing comparison
- Prioritized action plan
- 30-day optimization roadmap
- KPI dashboard structure
- Fully optimized sample product listing
- Responsive layout and print/export button

## Run locally
No build tools are required.

Option 1: double-click `index.html`.

Option 2: from this folder run:
`python -m http.server 5500`

Then open:
`http://localhost:5500`

## Note
The numbers and competitor observations are a presentation/demo model built around the scenario provided in the assignment. They should be replaced with real store/competitor data if such data is supplied.
